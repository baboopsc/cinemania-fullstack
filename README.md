# Cinemania Full-Stack Web Platform

Cinemania is a dynamic movie discovery and tracking platform featuring a responsive frontend and a robust backend API.

##  Tech Stack
* **Frontend:** JavaScript (Vite), HTML5, CSS3
* **Backend:** TypeScript (NestJS), Node.js, SQLite
* **External API:** TMDB API Integration

## Project Structure
* `/frontend`: Contains the Vite-based user interface, modular CSS components, and TMDB API data consumption logic.
* `/backend`: Contains the NestJS RESTful API, database models, CORS configurations, and user/comment endpoints.
